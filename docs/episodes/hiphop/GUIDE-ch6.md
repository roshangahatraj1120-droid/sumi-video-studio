## Notes
- **Your 18 slides have their titles baked in**, so the text couldn't move. I rebuilt each idea as
  animation in the same style (dark, red accents, tape labels), and cropped the clean photo areas
  (vinyl, cables, records) for B-roll. Slide 06's red "Grand Wizzard Theodore" text and slide 17's
  calendar had overlapping letters, so those were left out.
- **Bambaataa:** the script presents him only for his musical role, which is accurate. Since 2016 he
  has faced serious sexual-abuse allegations, which he has denied, and many viewers will know this. Clip
  **03b** adds one neutral line about it; **03** doesn't. Check the current status of the case before
  publishing either way.
- Names appear only as typography, never on a face. All pictures are AI reconstructions.
